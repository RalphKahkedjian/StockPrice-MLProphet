# StockPrice-MLProphet
A project that predicts stock price movements using machine learning classifiers and forecasts future stock prices using Facebook Prophet. This project demonstrates both classification (up/down prediction) and time series regression (actual price prediction).

Title:

Stock Trend & Price Forecasting with Machine Learning and Prophet

Description:

A project that predicts stock price movements using machine learning classifiers and forecasts future stock prices using Facebook Prophet. This project demonstrates both classification (up/down prediction) and time series regression (actual price prediction).

Features:

Predict next-day stock movement (up/down) using Logistic Regression, Decision Tree, Random Forest, and SVM.
Forecast future stock prices using Facebook Prophet.
Visualize historical and predicted stock prices with Matplotlib.
Compare model performances with accuracy charts.
